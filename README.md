# 📚 E-Learning Platform

A beginner-friendly **E-Learning Platform** developed as a **First Semester Software Engineering Project**. The project demonstrates the basic concepts of software development by providing separate modules for students and administrators.

---

## 📖 Project Overview

The E-Learning Platform is designed to provide a simple and user-friendly learning environment where students can register, access courses, take quizzes, monitor their performance, and receive certificates. The administrator can manage student records and monitor the overall system.

---

## ✨ Features

### 👨‍🎓 Student Module
- Student Registration
- Secure Login
- View Available Courses
- Attempt Quizzes
- Track Performance
- Certificate Generation

### 👨‍💼 Admin Module
- Admin Login
- View Student Records
- Monitor Student Performance
- Manage Student Information
